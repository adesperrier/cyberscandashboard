Guide d'Installation

Démarrez avec CyberScan en quelques minutes

1
Installer les dépendances

Installez Flask et les modules nécessaires :

pip install -r requirements.txt
2
Installer Nmap

Windows : Téléchargez depuis nmap.org

choco install nmap

Linux (Ubuntu/Debian) :

sudo apt-get install nmap
3
Lancer l'application

Démarrez le serveur Flask :

python app.py
4
Accéder à l'interface

Ouvrez votre navigateur :

http://127.0.0.1:5000
