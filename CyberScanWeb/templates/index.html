Python 3.10+ Requis

Nmap Optionnel

Dépannage & FAQ
« Python n'est pas reconnu »

Réinstallez Python en cochant "Add Python to PATH" lors de l'installation. Redémarrez ensuite votre terminal.

« Port déjà utilisé »

setup.py recherche automatiquement le prochain port disponible (5000–9000). Consultez la console pour l'URL exacte.

« Nmap introuvable »

L'application fonctionne sans Nmap, mais le scan réseau sera désactivé. Installez Nmap pour activer toutes les fonctionnalités.

« Module not found »

Relancez setup.py / start.bat — il installe automatiquement toutes les dépendances.
