Dépannage & FAQ

Cause : Python n'est pas dans le PATH système.

Solution :

  1. Réinstallez Python depuis python.org
  2. ⚠️ IMPORTANT : Cochez la case "Add Python to PATH" pendant l'installation
  3. Relancez votre terminal/CMD après l'installation
  4. Testez : python --version

Cause : Les dépendances Python ne sont pas installées.

Solution : Installez-les manuellement :

pip install -r requirements.txt

Cause : Un autre processus utilise le port 5000.

Solution : setup.py trouve automatiquement un port libre (5000-9000).

Si le problème persiste, tuez le processus :

lsof -i :5000 | grep -v PID | awk '{print $2}' | xargs kill -9

Cause : Nmap n'est pas installé.

L'app fonctionne mais le scan réseau ne marche pas.

Solution : Installez Nmap :

L'application ouvre automatiquement votre navigateur sur :

http://127.0.0.1:5000

Si le navigateur ne s'ouvre pas :

  1. Ouvrez manuellement votre navigateur
  2. Collez l'URL ci-dessus
  3. Appuyez sur Entrée
Installer Nmap
Windows

Téléchargez directement :

Télécharger Nmap

Ou avec Chocolatey :

choco install nmap
Linux (Ubuntu/Debian)
sudo apt-get install nmap
macOS
brew install nmap
Vérifier l'installation
nmap --version
