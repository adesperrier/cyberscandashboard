# 🚀 CyberScan Dashboard - Démarrage Rapide

## ⚡ 30 secondes pour lancer l'app

### Windows
```bash
cd CyberScanSoft
run.bat
```

### Linux / Mac
```bash
cd CyberScanSoft
chmod +x run.sh
./run.sh
```

**C'est tout!** L'application démarre automatiquement.

---

## 📋 Installation Complète

### Prérequis

- **Python 3.10+** → https://www.python.org
- **Nmap** (optionnel) → https://nmap.org

### Étapes

**1. Cloner le projet**
```bash
git clone https://github.com/adesperrier/cyberscandashboard.git
cd cyberscandashboard
```

**2. Lancer l'application**

Windows:
```bash
cd CyberScanSoft
run.bat
```

Linux/Mac:
```bash
cd CyberScanSoft
./run.sh
```

**3. C'est prêt!**
- L'app démarre
- Le navigateur s'ouvre
- Vous pouvez scanner le réseau

---

## 🎯 Premier Scan

1. **Cible** : `127.0.0.1` ou votre IP locale
2. **Mode** : Quick (rapide)
3. **Cliquez** : "Scanner"
4. **Résultats** : S'affichent en bas

---

## 🐛 Problèmes Courants

**"Python n'est pas reconnu"**
- Réinstallez Python avec "Add to PATH"
- Redémarrez le terminal

**"pip command not found"**
- Linux: utiliser `pip3` au lieu de `pip`
- Windows: réinstallez Python

**"Nmap introuvable"**
- Le scan réseau ne fonctionnera pas
- Installez Nmap depuis https://nmap.org
